# Password Strength Checker

## Project Description
This project is a Password Strength Checker developed using Python. It checks the strength of a password based on security rules and classifies it as Weak, Medium, or Strong.

## Features
- Checks password length
- Checks uppercase letters
- Checks lowercase letters
- Checks numbers
- Checks special characters
- Gives a password score
- Suggests how to improve weak passwords

## Technologies Used
- Python 3
- Regular Expressions (re module)
- Visual Studio Code

## How to Run
1. Open the project in VS Code.
2. Run the password_checker.py file.
3. Enter a password.
4. View the password strength result.
