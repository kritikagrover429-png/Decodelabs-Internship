# Basic Encryption & Decryption (Caesar Cipher)

## Project Description
This project implements a simple Caesar Cipher encryption and decryption program using Python. It encrypts user-entered text using a shift value and then decrypts it back to the original text.

## Features
- Encrypts text using Caesar Cipher
- Decrypts encrypted text
- Supports uppercase and lowercase letters
- Preserves numbers and special characters
- User chooses the shift value

## Technologies Used
- Python 3
- Visual Studio Code

## How to Run
1. Open the project in VS Code.
2. Run `caesar_cipher.py`.
3. Enter the text.
4. Enter the shift value.
5. View the encrypted and decrypted output.
