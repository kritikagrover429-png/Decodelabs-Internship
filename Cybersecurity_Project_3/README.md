# Phishing Awareness Analyzer

## Project Description
This project analyzes emails or messages to identify possible phishing attempts. It detects suspicious keywords and links to help users recognize phishing attacks.

## Features
- Detects suspicious keywords
- Detects URLs in messages
- Lists phishing red flags
- Explains why the message is unsafe

## Technologies Used
- Python 3
- Visual Studio Code
- Python re module

## How to Run
1. Open the project in VS Code.
2. Open the terminal.
3. Run:
   python phishing_analyzer.py
4. Enter or paste a message.
5. View the phishing analysis result.
